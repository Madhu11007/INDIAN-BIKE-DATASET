# Indian Bike Analysis Dashboard

## Project Overview
Analyzed 1,000 Indian bike records to identify market trends, pricing patterns, brand performance, and customer preferences. Developed an interactive dashboard using Microsoft Excel to transform raw data into meaningful business insights.

## Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis

## Key Features
- Brand-wise bike performance analysis
- Comparison of ex-showroom and on-road prices
- Engine capacity analysis
- Bike segment analysis
- Fuel tank capacity comparison
- Customer ratings and overall score analysis
- Interactive filtering using slicers

## Key Performance Indicators (KPIs)
- Total On-Road Price
- Total Ex-Showroom Price
- Average Overall Score
- Maximum Fuel Tank Capacity

## Project Objectives
- Understand the Indian two-wheeler market.
- Compare different bike brands and their pricing.
- Identify popular bike segments.
- Analyze engine capacity and fuel tank specifications.
- Present useful insights through interactive visualizations.

## Key Insights
- Compared pricing differences across bike brands.
- Identified variations in engine capacity among bike segments.
- Analyzed customer ratings to understand bike performance.
- Explored market trends through interactive charts.

## Conclusion
This project demonstrates my ability to clean, analyze, and visualize data using Microsoft Excel. The dashboard helps users understand bike market trends and make data-driven comparisons.
