# Indian Bike Analysis Dashboard

## Project Overview
Analyzed 1,000 Indian bike records to identify market trends, pricing patterns, and customer preferences.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- Data Analysis

## Key Features
- Brand-wise bike analysis
- Price comparison
- Engine capacity analysis
- Fuel tank capacity analysis
- Interactive dashboard with KPI metrics

## Project Outcome
Generated meaningful insights into bike brands, pricing, and market trends to support data-driven decision-making.
